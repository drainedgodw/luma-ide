# About Luma

Luma is a desktop code editor for people who want a clear view of their project and its Git history.

The editor works without Git. Open a folder, edit files, search the workspace and use the terminal. If the folder is a Git repository, Luma adds status, changes, history, recovery and GitHub tools around the same workspace.

Luma is built with Electron, React, TypeScript and CodeMirror. It is free software under the MIT license.

## Liquid Glass

Liquid Glass is an optional theme. It uses the current desktop wallpaper behind the interface and applies frosted panels on top.

The blur amount is adjustable in **Settings → Appearance & sound → Liquid Glass blur**:

- `0` — no blur;
- values in the middle — lighter glass;
- the far right — stronger frosted glass.

The value is saved locally with the rest of Luma's settings.
